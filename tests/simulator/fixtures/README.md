# Hosted-source conformance snapshots

`uint-range.f` is a byte-for-byte snapshot of
`akashic/utils/uint-range.f` from Akashic revision
`8e65ccf5e62d00b47e4cb846a379d12ae9297f3b`. Its SHA-256 digest is
`11b9b0d2a87466aec24b1952f921226f4ae4681e396a677136a5d17152b103e8`.

The snapshot is a revision-bound cross-repository conformance input, not a
forked simulator implementation. Integration qualification loads the ordinary
Akashic checkout; this copy keeps the focused MegaPad unit deterministic and
self-contained.
